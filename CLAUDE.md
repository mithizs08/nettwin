# CLAUDE.md

This project is NetTwin, a portfolio project for the UTS Telecom Research Unit Project D.A.R.T. internship.

- `PLAN.md` is the source of truth. Read it in full at the start of every session, along with `docs/decision_log.md`.
- Always activate the conda env first: `conda activate nettwin`.
- Work one phase at a time and stop after each phase to summarise.
- Follow the honesty rules in PLAN.md section 1: telemetry is synthetic, topologies are public, none of this is Telstra's network, every reported number comes from a script output, and negative results are reported.
- No em dashes in any prose.
